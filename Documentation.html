Cricscore - Android App Setup & Rebranding Guide

Thank you for purchasing Cricscore. Follow this complete step-by-step guide to configure Firebase, rebrand the app (Package ID, Name, Colors, Icon, Splash Screen), and generate a Signed Release APK/AAB.

1. Opening the Project in Android Studio

  1. Extract the downloaded ZIP archive to a folder on your computer.
  2. Open Android Studio (Ladybug / Meerkat or newer) with JDK 21.
  3. Click File → Open and select the extracted project root folder.
  4. Wait for Gradle sync to complete.

2. Changing the Android Package ID (Application ID)

  1. Open app/build.gradle.kts.
  2. Locate namespace and applicationId inside the android { ... } block: 
    android {
    namespace = "com.yourcompany.cricscore"
    defaultConfig {
        applicationId = "com.yourcompany.cricscore"
        ...
    }
}
  3. Replace the existing ID with your own unique package name and click Sync Now.

3. Rebranding: App Name, Strings, Colors, Assets & Splash Screen

  • App Name & Strings: Open app/src/main/res/values/strings.xml and change <string name="app_name">Cricscore</string> along with any custom labels.
  • Theme Colors: Open app/src/main/java/com/example/ui/theme/Color.kt and Theme.kt to customize primary, secondary, and background colors across the entire Jetpack Compose UI.
  • App Icon: Right-click the app/src/main/res folder in Android Studio → New → Image Asset → select Launcher Icons (Adaptive and Legacy), upload your 512x512 logo, and click Finish.
  • Splash Screen & Assets: Replace custom graphics inside app/src/main/res/drawable/ and edit the splash composable in MainActivity.kt (search for Splash) to update the splash logo, title, or duration.

4. Firebase Configuration (Authentication & Cloud Firestore)

  1. Go to Firebase Console and create a new project.
  2. Click Add App → Android, enter your exact applicationId from Step 2, and register the app.
  3. Download the generated google-services.json file and place it inside the app/ directory (replacing the placeholder file).
  4. In Firebase Console → Authentication → Sign-in method, enable Email/Password and Google.
  5. Copy your Web Client ID from Firebase Authentication (Google provider settings) and paste it into app/src/main/res/values/strings.xml (or ci_strings.xml) under default_web_client_id.
  6. In Firebase Console → Cloud Firestore → Rules, paste the rules from the included firestore.rules file and click Publish.

5. Updating In-App Update URL & Start.io Ad ID

  • In-App Update Link: In your Firestore database, create collection app_config → document version_info with string fields latestVersion (e.g., v1.0.1) and downloadUrl (your own APK or Play Store URL).
  • Start.io Ads (Optional): Open app/src/main/AndroidManifest.xml and replace YOUR_STARTIO_APP_ID with your own Start.io App ID.

6. Generating a Signed Release APK / AAB

  1. In Android Studio top menu, click Build → Generate Signed Bundle / APK...
  2. Select Android App Bundle (AAB) (for Google Play Store) or APK and click Next.
  3. Click Create new... to generate a new .jks keystore file, fill in your keystore password, key alias, and validity, and save it safely.
  4. Select release build variant and click Create. Your signed file will be generated in app/release/.
